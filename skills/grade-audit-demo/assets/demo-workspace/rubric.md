# Lab 3 rubric (fixed before grading; constant across all students)

| Component | Weight | Judged from |
|---|---|---|
| Data cleaning | /5 | report.md (what was removed and why); code where present |
| Analysis correctness | /5 | report.md numbers and test choice; code where present |
| Figures | /5 | report.md — at least two relevant figures, labeled and captioned |
| Write-up clarity | /5 | report.md — methods, results, one limitation, within length |

Total /20. Session logs are never scored (see CLAUDE.md regime); using the course
assistant is allowed and carries no penalty — but credit for an *idea* goes to whoever
originated it, per the session log.
